## Objetivo

Desarrollar un modelo predictivo que clasifique a los deudores de crédito según su nivel de riesgo de incumplimiento (Alto, Medio, Bajo).

Se entrenaron y evaluaron tres modelos:
- Regresión Logística
- Árbol de Decisión
- Random Forest
